# Source data placement

The original public workbook is intentionally not included in this repository.

Download dataset version 1 using DOI `10.17632/687fw2n74b.1`, then place the workbook at:

```text
source_data/Data for Dynamic modeling of NOX emission in a 660 MW coal-fired boiler with LSTM/data.xlsx
```

Do not rename the workbook or parent directory unless `src/config.py` is updated accordingly.
