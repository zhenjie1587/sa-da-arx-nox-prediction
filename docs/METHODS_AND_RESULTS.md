# 方法与结果说明

## 1. 研究问题

研究对象是660 MW燃煤锅炉A/B两侧NOx浓度的一分钟短时动态预测。核心问题不是继续堆叠深度网络，而是回答：

> 在锅炉频繁变负荷且部分运行传感器发生随机丢失、连续掉线或关键测点整段失效时，能否保持足够准确且能够给出不确定性范围的NOx预测？

## 2. 方法定义

主方法记为SA-DA-ARX：

- SA：Sensor Availability，传感器可用性感知；
- DA：Delay Aware，运行变量时滞感知；
- ARX：Autoregressive with Exogenous Inputs，含外生变量的自回归模型。

模型输入由三部分组成：

1. 当前时刻27个运行参数；
2. 每个运行参数经训练集交叉相关选择的最佳0–10分钟时滞；
3. A/B两侧NOx的前1–10分钟历史值。

F01选择10分钟时滞，F16选择5分钟，F26和F27选择6分钟。具体时滞见`results/tables/selected_lags.csv`。

## 3. 传感器掉线增强

缺失专家的训练集由四份数据拼接：

- 完整训练数据；
- 10%随机缺失；
- 20%随机缺失；
- 30%随机缺失。

缺失值用训练数据中位数填补，同时添加缺失指示变量。目标历史值不参与人工掉线，因为本研究评估的是运行传感器缺失，不是NOx分析仪永久失效。

## 4. 严格性控制

- 所有时滞只用训练集选择；
- 关键传感器F26只用校准集置换重要性确定；
- 测试集保持连续时间顺序；
- 随机缺失和块缺失重复5次并报告均值与标准差；
- 统计检验使用成对绝对误差的单侧Wilcoxon符号秩检验；
- 预测区间不使用测试标签校准。

## 5. 核心结果

完整数据下，SA-DA-ARX的A/B侧RMSE分别约为9.30和10.00 mg/Nm³，宏平均为9.65 mg/Nm³。原工作簿LSTM宏平均RMSE为12.20 mg/Nm³。

30%随机缺失时：

- SA-DA-ARX：12.38 ± 0.09 mg/Nm³；
- DA-ARX-Ridge：19.40 ± 0.31 mg/Nm³；
- Robust-DA-ARX：12.38 ± 0.09 mg/Nm³；
- ExtraTrees-ARX：约15.3 mg/Nm³。

双专家切换的主要意义是：完整数据时保留干净专家的9.65 mg/Nm³精度；出现缺失时获得缺失专家的鲁棒性。单独使用缺失专家会使完整数据误差升至10.77 mg/Nm³。

关键变量F26整段掉线时，主方法RMSE为12.49 mg/Nm³；20%连续一小时块缺失时为11.49 ± 0.15 mg/Nm³。

分块95%保形区间在各场景的实测覆盖率约为94.5%–97.2%。区间会随缺失程度增宽，因此能反映模型在掉线场景中的不确定性上升。

## 6. 可写入论文的结论

1. 动态和时滞信息比单纯更换黑箱算法更重要：Static-Ridge误差35.03，AR-Ridge降至11.15，加入运行参数时滞后进一步降至9.65 mg/Nm³。
2. 未增强动态模型在30%缺失时误差翻倍；掉线增强能将误差控制在12.38 mg/Nm³。
3. 可用性感知切换同时解决了“鲁棒训练牺牲完整数据精度”的问题。
4. 升降负荷场景明显难于稳态场景，应在结果讨论中单独分析。

## 7. 不能写入论文的结论

- 不能声称数据来自国能蚌埠发电厂；
- 不能声称已经完成现场部署或在线闭环控制；
- 不能将F02–F27强行解释成具体风门、氧量或煤量；
- 不能声称模型完全替代NOx分析仪；
- 不能把人工缺失写成真实传感器故障记录。
